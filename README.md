# holler

Field notes from a small local-inference fleet. Site: <https://t0mj.github.io/holler/>.

Hugo site, static, zero JavaScript. Markdown in `content/`; hand-rolled minimal layout in
`layouts/`. RSS at `/holler/index.xml`.

Deploy: push to `main` → Actions builds Hugo 0.165 (extended) → `gh-pages` branch → GitHub
Pages (project site; `baseURL = /holler/` in `hugo.toml`).

**Public repo — public-safe content only.** See `AGENTS.md`.
